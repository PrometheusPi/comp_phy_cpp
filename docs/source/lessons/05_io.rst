Input/Output (I/O)
==================


Introduction
------------
To develop interactive programs loading input from file or from user input and returning result to screen or to file is essential.
Here, we discuss common methods in C++ to accomplish this.


Writing output to the screen
----------------------------
As already used a couple times before, we can write to the terminal using ``std::cout``.

.. code-block:: cpp

    std::cout << "text that you want to have on the terminal" << std::endl;

Reading input from a file
-------------------------
In many situations, you want to read data from a file.
In the following example, we read numbers from a text file.

Before attempting to open a file, we check whether it exists with ``std::filesystem::exists(filename)``.
A file handler is created with ``std::ifstream file(filename)``.
In the ``while`` loop, we extract data from the file via ``file >> num`` until there is no more data.


Writing output to a file
------------------------
Sometimes, you want to store your results and not just print them to a screen once.
To do this, C++ allows us to write to a file.
Similarly to reading from file, we create a file handler using ``std::ofstream outFile("filename")``.
We should check, whether the file was created.
And then we can stream to the file in a similar manar as we stream to ``std::cout`` when writing to the screen.
In the end, we have to close the file with ``outFile.close()``.

Controlling the formatting of the output
----------------------------------------
Sometimes, you want yourtext output to follow specific format rules, like how many didgets after the comma should be given, or whether to use standard comma numbers or scientific notation.
C++ overs a variety of method to do that.
One introduced recebtly with C++20 is format strings.

You give string with information on formating in curly brackets as e.g. ``"{:.1f}"`` for floating pount number with one significant didget after the comma.
With ``std::fixed`` you can set fixed floating point output, while with ``std::scientific`` you set it to scientific notation.
