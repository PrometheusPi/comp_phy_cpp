Input/Output (I/O)
==================


Introduction
------------
To develop interactive programs loading input from file or from user input and returning result to screen or to file is essential.
Here, we discuss common methods in C++ to accomplish this.


Writing output to the screen
----------------------------
As already used a couple times before, we can write to the terminal using ``std::cout``.

.. code-block:: cpp

    std::cout << "text that you want to have on the terminal" << std::endl;

-------------------------
In many situations, you want to read data from a file.
In the following example, we read numbers from a text file.

Before attempting to open a file, we check whether it exists with ``std::filesystem::exists(filename)``.
A file handler is created with ``std::ifstream file(filename)``.
In the ``while`` loop, we extract data from the file via ``file >> num`` until there is no more data.
